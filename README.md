# PNM07 · บันทึกตัวอย่างน้ำมัน

เว็บแอปบนโทรศัพท์สำหรับบันทึกการตรวจเก็บตัวอย่างน้ำมันเชื้อเพลิงที่สถานีบริการ ติดตั้งเป็นไอคอนบนหน้าจอได้ทั้ง iPhone และ Android ใช้งานได้แม้ไม่มีสัญญาณ และทุกเครื่องเห็นข้อมูลชุดเดียวกัน

**ที่อยู่แอป:** https://worrapojs28-hash.github.io/PNM07/

## ทำอะไรได้บ้าง
- **เคส:** เลขเคสรันอัตโนมัติ (`SCDC7-69-10-001`), วันที่เก็บ, สถานีบริการ, จังหวัด/อำเภอ/ตำบล, พิกัดจาก GPS หรือแตะบนแผนที่, ภาพถ่าย ณ จุดเก็บ
- **ตัวอย่าง:** ชนิดน้ำมัน, สี, เลขซีล, ผลตรวจ (RON, เอทานอล, เมทานอล, ความหนาแน่น, การกลั่น, จุดวาบไฟ, กำมะถัน, FAME) พร้อมภาพหน้าจอเครื่องมือทุกค่า
- **เทียบเกณฑ์ตามประกาศกรมธุรกิจพลังงานอัตโนมัติ** โดยเลือกเกณฑ์ฉบับที่มีผลใน "วันที่เก็บตัวอย่าง" เช่น FAME ของ B7 ช่วง 14 มี.ค.–13 ก.ย. 2569 ใช้ 6.6–7.0% นอกช่วงนั้นใช้ 5.0–7.0%
- **แผนที่:** ดูทุกจุดเก็บในปี กรองตามเดือน/จังหวัด/สถานะ สีหมุดบอกสถานะ (แดง = มีตัวอย่างไม่เป็นไปตามเกณฑ์)
- **หลักฐาน:** ภาพทุกภาพมีค่า SHA-256 ตรวจสอบได้, บันทึกการส่งมอบพร้อมลายมือชื่อ, ประวัติการแก้ไขทุกครั้ง, ล็อกเคสเมื่อยืนยันผล
- **รายงานรายเคส** (พิมพ์/บันทึก PDF), **สถิติ** รายเดือน/รายจังหวัด, **ส่งออก CSV** และสำรองข้อมูล JSON
- **ผู้ใช้ 3 ระดับ:** แอดมิน (จัดการผู้ใช้และเกณฑ์, ปลดล็อกเคส) · เจ้าหน้าที่ (บันทึกเคสและผล) · ผู้บังคับบัญชา (ดูอย่างเดียว)

## ตั้งค่าครั้งแรก (ทำครั้งเดียว ประมาณ 15 นาที)

### ก. GitHub Pages
1. เปิด https://github.com/worrapojs28-hash/PNM07 › **Settings** › **General** › เลื่อนลงล่างสุด ถ้ายังเป็น Private ให้กด **Change visibility › Public**
2. **Settings › Pages** › Source: **Deploy from a branch** › Branch: **main** / **(root)** › **Save**
3. รอ 1–2 นาที แล้วเปิด https://worrapojs28-hash.github.io/PNM07/ จะเห็นข้อความ "ยังไม่ได้เชื่อมต่อ Firebase" (ถูกต้อง)

### ข. Firebase
1. เข้า https://console.firebase.google.com › **Add project** › ตั้งชื่อ เช่น `pnm07` (ปิด Google Analytics ได้)
2. **Build › Authentication › Get started** › เลือก **Email/Password** › เปิด **Enable** › Save
3. ใน Authentication › แท็บ **Settings › Authorized domains** › **Add domain** › พิมพ์ `worrapojs28-hash.github.io`
4. **Build › Firestore Database › Create database** › Location: **asia-southeast1 (Singapore)** › **Start in production mode**
5. แท็บ **Rules** › ลบข้อความเดิมทั้งหมด › เปิดไฟล์ [`firestore.rules`](firestore.rules) ใน GitHub › กดปุ่ม **Copy raw file** › วาง › **Publish**
6. **Project settings** (รูปเฟือง) › **Your apps** › กดไอคอน `</>` › ตั้งชื่อแอป › **Register app** › คัดลอกค่าใน `firebaseConfig = { ... }`

### ค. ใส่ค่าเชื่อมต่อ
ส่งค่า `firebaseConfig` ให้ Claude ใส่ให้ หรือแก้เองที่ไฟล์ [`firebase-config.js`](firebase-config.js) (กดรูปดินสอใน GitHub) ให้เป็นแบบนี้ แล้วกด **Commit changes**
```js
export const firebaseConfig = {
  apiKey: "AIza...",
  authDomain: "pnm07.firebaseapp.com",
  projectId: "pnm07",
  storageBucket: "pnm07.appspot.com",
  messagingSenderId: "...",
  appId: "..."
};
```
ค่านี้ไม่ใช่ความลับ ความปลอดภัยของข้อมูลอยู่ที่กฎ `firestore.rules`

### ง. เริ่มใช้งาน
1. เปิดแอป › **สมัครใช้งาน** ด้วยอีเมลของคุณ › กด **ฉันคือผู้ดูแลระบบ** (ทำได้คนแรกคนเดียว)
2. ไปที่ **ตั้งค่า**:
   - ตรวจทาน **เกณฑ์ตามประกาศกรมธุรกิจพลังงาน** ทุกแถวกับประกาศฉบับจริง แล้วติ๊ก "ตรวจทานแล้ว" (แถวที่ยังไม่ตรวจทานมีป้าย "รอตรวจทาน")
   - **เชิญผู้ใช้:** ใส่อีเมลและเลือกสิทธิ์ (เจ้าหน้าที่ / ผู้บังคับบัญชา / แอดมิน)
3. ผู้ถูกเชิญเปิดแอป › **สมัครใช้งาน** ด้วยอีเมลที่ถูกเชิญ › กด **ส่งอีเมลยืนยัน** › กดลิงก์ในอีเมล › กลับมากด **ยืนยันแล้ว เข้าใช้งาน**
4. ติดตั้งบนโทรศัพท์:
   - iPhone: เปิดใน **Safari** › ปุ่มแชร์ › **เพิ่มไปยังหน้าจอโฮม**
   - Android: เปิดใน **Chrome** › เมนู ⋮ › **ติดตั้งแอป**

## เมื่อมีประกาศ ธพ. ฉบับใหม่
**ตั้งค่า › เกณฑ์ตามประกาศ › + เพิ่มเกณฑ์**: เลือกชนิดน้ำมันและรายการ ใส่ค่าต่ำสุด/สูงสุด วันที่เริ่มมีผล และชื่อประกาศ **ไม่ต้องลบเกณฑ์เดิม** (ถ้าเกณฑ์เดิมสิ้นสุดแล้วให้ใส่ "ถึงวันที่") เคสเก่าจะยังเทียบกับฉบับที่ใช้ในวันที่เก็บตัวอย่าง

## ข้อควรรู้
- **ภาพเก็บใน Firestore** (ย่อเหลือ 150–400 KB ต่อภาพ) แพ็กเกจฟรีเก็บได้ 1 GB หรือประมาณ 3,000–5,000 ภาพ ถ้าใกล้เต็มให้อัปเกรดเป็นแพ็กเกจ Blaze (จ่ายตามการใช้งานจริง)
- **ค่า Hash** คิดจากไฟล์ภาพที่ระบบย่อและจัดเก็บจริง ถ้าต้องใช้ไฟล์ต้นฉบับจากกล้องเป็นพยานหลักฐาน ให้เก็บไฟล์ต้นฉบับแยกไว้ด้วย
- **ออฟไลน์:** ต้องเข้าสู่ระบบแบบออนไลน์อย่างน้อยหนึ่งครั้งก่อน แถบบนจะแสดง "ซิงก์แล้ว / รอส่ง N / ออฟไลน์" และอย่าออกจากระบบขณะยังมีรายการรอส่ง พื้นหลังแผนที่ต้องใช้อินเทอร์เน็ต แต่หมุดยังแสดงได้
- **เลขเคส:** ถ้าเจ้าหน้าที่สองคนสร้างเคสพร้อมกันขณะออฟไลน์ อาจได้เลขเดียวกัน หน้ารายการจะติดป้าย "เลขเคสซ้ำ" ให้แก้เลขได้
- **อัปเดตแอป:** เมื่อมีเวอร์ชันใหม่ ให้ปิดแอปให้สนิทแล้วเปิดใหม่
- **แผนที่** ใช้ OpenStreetMap ผ่าน Leaflet (ฟรี) ปุ่มพิกัดในหน้าเคสเปิด Google Maps ได้

## สำหรับผู้พัฒนา
- แก้โค้ดที่ `parts/` แล้วรัน `python3 build.py` (สร้าง `app.js`, `styles.css` และเปลี่ยนเลขเวอร์ชันใน `sw.js`)
- ทดสอบ: `node tests/run.js` (Playwright + Firebase จำลองใน `tests/mock/` ซึ่งจำลองกฎความปลอดภัยด้วย)
- โครงสร้างข้อมูล Firestore:

| คอลเลกชัน | เนื้อหา |
|---|---|
| `meta/owner` | ผู้ก่อตั้ง (ผู้ดูแลระบบคนแรก) |
| `meta/settings` | ชื่อหน่วยงาน, คำนำหน้าเลขเคส, ชนิดน้ำมัน, เกณฑ์ (`criteria`: fuel, test, min, max, from, to, ref) |
| `members/{uid}` | role: admin / officer / commander / disabled |
| `invites/{email}` | คำเชิญ (อีเมลตัวพิมพ์เล็ก) |
| `cases` | caseNo, date (YYYY-MM-DD), station, province, district, subdistrict, location, photos, status, locked |
| `samples` | caseId, caseDate, seq, fuel, color, sealNo, results, photos, status, locked |
| `photos` | ภาพ JPEG (data URL) + sha256 (เพิ่มได้อย่างเดียว) |
| `custody` | การส่งมอบ + ลายมือชื่อ (เพิ่มได้อย่างเดียว) |
| `audit` | ประวัติการแก้ไข (เพิ่มได้อย่างเดียว) |
